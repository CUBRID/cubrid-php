CUBRID PHP Driver Release Notes

Releases: https://github.com/CUBRID/cubrid-php/releases

11.3.0.0001

Supported platforms

PlatformPHP
Linux x86_648.3, 8.4, 8.5
Windows x64 (Visual Studio 2022, vs17)8.4, 8.5 (NTS, TS)

CCI: 11.2.0.0040 (cci-src 9965aa8)

Changes

  • Ported the driver to PHP 8 (php_cubrid8.c) and supports PHP 8.3, 8.4 and 8.5.
  • Dropped PHP 5.x and 7.x, and the old Visual Studio project files. Use an earlier driver release for PHP 8.2 or earlier.
  • Fixed crashes in cubrid_close_request() and cubrid_fetch_object().
  • Distributed with PIE (pie install cubrid/cubrid) and GitHub Releases instead of PECL.
  • Release packages:
    • Linux: php_cubrid-11.3.0.0001-src.tgz (source including CCI)
    • Windows: php_cubrid-11.3.0.0001-<8.4|8.5>-<nts|ts>-vs17-x86_64.zip (php_cubrid.dll and cascci.dll)
    • A .sha256 checksum file for each package
  • New build scripts: build.sh (Linux), build_win.ps1 (Windows), and release scripts script/release.sh and script/release.ps1. See build-guide.html.
  • Added composer.json (PIE package cubrid/cubrid) and LICENSE; removed the PECL package.xml.
